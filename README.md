## 📖 Overview

Smart Inventory & Sales Intelligence System is a full-stack web application designed for small businesses to simplify inventory operations and support data-driven decision-making.

The system automates inventory tracking, manages suppliers, purchases, and sales, provides interactive business analytics, and predicts future product demand using Machine Learning.

---

## ✨ Features

- 🔐 Secure User Authentication
- 👥 Role-Based Access Control (Admin & Staff)
- 📦 Product Management
- 🏢 Supplier Management
- 🛒 Purchase Management
- 💰 Sales Management (Cart-Based Billing)
- 🔄 Automatic Stock Updates
- ⚠️ Low Stock Alerts
- 📊 Interactive Dashboard
- 📈 Sales Analytics (Daily & Monthly) with Product Performance Reports
- 🤖 AI demand forecasting (Linear Regression via scikit-learn)
- 🔍 Search & Filtering
- 📱 Responsive Interface

# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/GangappaSH/smart-inventory.git
```

Move into project

```bash
cd smart-inventory
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```

# 🧠 AI Demand Forecasting

The application includes a Machine Learning module that predicts future product demand using **Linear Regression** trained on historical sales data.

This helps businesses:

- Reduce stock shortages
- Improve purchasing decisions
- Plan inventory more efficiently
